**What this means for which drivers Dexo should add.** SQL Server is free in both and is the biggest gap in Dexo's list. After it come ClickHouse (free in DbGate, paid in Beekeeper), Redis and MongoDB (the two non-SQL engines both offer), and libSQL/Turso (paid in both). The cheapest win is wire-compatible engines Dexo may already almost reach: CockroachDB, Redshift, Greengage and Yugabyte over the PostgreSQL driver, and TiDB over the MySQL driver. Both GUIs list these as separate engines, so a "tested with" matrix plus a few catalog quirks costs S to M per engine.

**Positioning.** Beekeeper charges for features Dexo already ships free: CSV import, native backup and restore, the JSON view of a row, editable grid with staged changes, schema compare (DbGate charges for it; Beekeeper has none), and AWS IAM, which Dexo can do through `password_command` (see the recipe idea below). DbGate's MCP server is read-only in Community; writes, `execute_query`, `insert_rows` and `update_rows` need Team Premium. Its server runs over HTTP with OAuth (`api/src/main.js` lines 185–192). Dexo's MCP is stdio-only but free, and lets agents write through approval grants.

## 3. GUI-only features not worth bringing to a TUI

| Feature (who) | Why not |
|---|---|
| Visual query designer (DbGate Premium) | Drag-and-drop joins have no keyboard equivalent that beats typing SQL with Dexo's completion. DbGate's free "Insert SQL JOIN" helper (`modals/InsertJoinModal.svelte`) is a simpler substitute: completion that proposes `JOIN t ON <fk condition>`. |
| Perspectives (DbGate Premium): nested drill-down tables | They need nested scrolling panes. Related rows plus FK labels give most of the value. |
| Full-schema ER diagram with drag layout and PNG export (both) | Free layout of 50+ tables does not fit a terminal grid. A neighbourhood view plus Mermaid/DOT export covers it. |
| Map view of GEO data (DbGate) | It needs tiles. Showing WKT/GeoJSON text in the value viewer is enough. |
| Spreadsheet interactions: drag-select ranges, paste ranges from Excel, column resize by mouse (Beekeeper) | Keyboard row and column selection plus copy formats already cover it, and multi-line terminal paste is unreliable. |
| Cloud team workspaces with per-item ACLs and live merge (`components/editor/MergeManager.vue`) (Beekeeper paid, DbGate Team Premium) | They require a hosted backend and accounts, against Dexo's local-only and no-telemetry stance. Git-shareable project files (section 2) are the native equivalent. |
| Theme marketplace and AI theme generator (DbGate) | Dexo's theme files are enough. |
| In-process plugin runtime (Beekeeper iframe plugins, DbGate npm plugins) | A Rust plugin ABI or WASM host is costly to maintain. "Pipe to command" plus MCP covers integration. |
| Web or Docker server mode (DbGate) | Out of scope. Dexo's remote story is SSH into a box and run the binary. |
| Query magics such as images, star ratings and progress bars (Beekeeper) | They are cosmetic. Only the unix-time and enum mapping parts are worth keeping, as value interpretations. |
| Font, zoom and window chrome settings (many Beekeeper requests) | The terminal owns these. |

## 5. Top 5 recommendations, ranked by value per effort

1. **Grid browsing quick wins: hide/show columns, filter by this cell, and a key for history search (S, about 3 days in total).** Column hiding is already half-built (`model.rs:336`, `hide_column`, with no caller). "Filter: col = value" appends to the WHERE bar, so the safety path stays the same. Binding history to Ctrl+R in the default and Emacs keymaps is a one-line keymap change. These are the actions people do 50 times a day.
2. **Cloud IAM recipes plus SSH `~/.ssh/config` and ProxyJump (S + M).** IAM is a paid feature in both GUIs, and Dexo already supports it through `password_command`. It only needs a docs section with tested commands for RDS, Azure and Cloud SQL, which is close to free and makes a good launch line ("AWS IAM, free"). ssh_config aliases and one jump hop close the remaining ops gap: Beekeeper #1434 and its full ssh_config support.
3. **FK and enum lookup in Insert Row and cell edit, plus edit-cell-in-`$EDITOR` (M + S).** This is the most-requested editing pain in Beekeeper (#1064 8 👍, #2278, #220 5 👍), and DbGate solves it with `DictionaryLookupModal`. A fuzzy picker over the referenced table fits the TUI well. `$EDITOR` for JSON and long text reuses the existing `ExternalEdit` flow.
4. **Relationships view plus `dexo schema erd --format mermaid|dot` (S + M).** ER diagrams were Beekeeper's 18-👍 request and are now paid there. Text export is cheap, works over CLI and MCP, and pastes into READMEs and PRs. A table-centred neighbourhood view is the part that fits a TUI. Skip full-schema layout.
5. **Result charts via ratatui `BarChart`, `Chart` and `Sparkline` (M).** DbGate keeps charts behind Premium and Beekeeper has none. Auto-detection following DbGate's `chartProcessor.ts` heuristic (date column to timeline, text column plus numbers to top-10 bars) behind `v` adds no dependency, and charts in a terminal stand out in demos, which the competitive-landscape memory says is where stars come from.
